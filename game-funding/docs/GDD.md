# Game Design Document (GDD)

## 1. Game Overview
- **Title**: Game Funding Project
- **Genre**: Strategy / Simulation / Mobile Idle
- **Target Audience**: Mid-core mobile gamers interested in resource management and progression.

## 2. Core Gameplay Loop
1. **Earn Resources**: Complete tasks, challenges, or idle generation.
2. **Upgrade Systems**: Spend currency to enhance production and unlock new mechanics.
3. **Progress**: Reinvest earnings into higher tier assets and unlocks.

## 3. Player Objectives
- Maximize funding rate per second.
- Unlock all features and complete long-term achievements.
- Optimize resource allocation for maximum return on investment.

## 4. Control & Interface
- Simple touch UI optimized for mobile screens.
- Clear indicators for active boosters, earnings, and monetization opportunities.
