# Game LiveOps & Continuous Development Roadmap

## 1. Update Cycle & LiveOps Strategy
- **Minor Updates (Bi-weekly)**: Bug fixes, balance tweaks, and new limited-time events (LTEs).
- **Major Content Updates (Monthly)**: New game features, additional IAP offers, and expanded upgrade trees.

## 2. Content Pipeline & Feature Rollout

### Phase 1: Launch & Core Foundation (Current)
- [x] Basic game loop and multiplier systems.
- [x] Hybrid monetization engine (Rewarded Ads + Offline Earnings).
- [x] Basic Security (SHA-256 local save encryption).
- [x] Core IAP integration (Remove Ads, VIP Pass, Permanent Boosters).

### Phase 2: Live Events & Engagement (Q3 2026)
- [ ] **Battle Pass / Season Pass System**: Monthly rewards for active players.
- [ ] **Daily Login Rewards**: Escalating streak rewards to boost retention.
- [ ] **Dynamic Pricing Engine**: Customized IAP discounts based on player activity.

### Phase 3: Social & Multiplayer Expansion (Q4 2026)
- [ ] **Global & Friends Leaderboards**: Cloud-synced via AuthManager.
- [ ] **Guilds / Investor Clubs**: Co-op passive earning bonuses for groups.
- [ ] **Cloud Save Auto-Sync**: Seamless cross-platform account recovery.

## 3. Ad & Monetization Optimization
- **A/B Testing**: Continuously testing ad placements (e.g., placement timing, reward values).
- **Ad Frequency Capping**: Ensuring high player retention by preventing ad fatigue.
