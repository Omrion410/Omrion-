# UI/UX & Graphic Design Specification

## 1. Color Palette (لوحة الألوان)
- Primary Background: #0D1117 (Dark Navy)
- Secondary Cards: #161B22 (Slate Dark)
- Accent Gold: #FFD700 (Gems & Income)
- Emerald Green: #2EA043 (Upgrades)
- Electric Violet: #8A2BE2 (VIP & Actions)
- Text Primary: #FFFFFF (White)
- Text Muted: #8B949E (Ash Gray)

## 2. Branding Assets (الشعار والأيقونة)

### App Icon Concept
- Square with rounded corners.
- Dark blue gradient background.
- Glowing gold and emerald growth arrow with sparkling diamonds.
- AI Prompt: "A modern 3D mobile game icon, dark blue gradient background, glowing gold and emerald green growth arrow with diamonds, gold frame, ultra-detailed, 8k"

### Game Logo Concept
- Font: Extra Bold, Modern Sans-serif.
- Title: GAME FUNDING
- Style: 3D Gold gradient with light ambient glow.

## 3. Screen Layouts (توزيع الشاشات)

### Screen 1: Main Dashboard
- Header: User Profile, Balance ($), Gems Count, Settings Icon.
- Center Area: Active Investment Hub, Income Multiplier Status.
- Main Action: Large Glowing Boost Button (Tap to Generate).
- Bottom Navigation Bar: Home, Upgrades, Store, Ranking.

### Screen 2: Upgrades & Investment Cards
- Investment Card: Icon + Project Name + Current Level.
- Upgrade Action: Green Button with cost and yield (e.g., Upgrade: $50.00 / +$5 per sec).

### Screen 3: Store & Monetization
- VIP Banner: Remove Ads + Permanent 2x Boost ($4.99).
- Rewarded Ad Banner: Watch Ad for 30 Min Double Income (Free).
- Currency Shop: Gem Packs (100, 500, 1000 Gems).

## 4. Controls & Feedback
- Tap Effect: Scale animation + floating text (+$10.00) fading upwards.
- Auto-Buy: Press and hold on upgrade button triggers rapid buy every 0.1s.
- Haptics: Light vibration on tap, strong celebratory vibration on purchase.
