# High-Level Design Overview

## Vision Statement
To build an engaging, scalable mobile game loop centered around strategic resource investment, high retention loops, and optimized monetization funnels.

## Key Pillars
- **Accessibility**: Simple to understand, touch-friendly UI.
- **Depth**: Interlocking systems that reward strategic planning.
- **Value**: Transparent monetization that feels rewarding rather than punitive.

## Target Metrics
- **Day 1 Retention**: > 40%
- **Day 7 Retention**: > 15%
- **ARPPU**: Optimized via balanced IAP and Rewarded Ad integration.
