# Systems Design Breakdown

## 1. Economy System
- **Soft Currency**: Standard gold/coins earned through gameplay.
- **Hard Currency**: Gems/Gems used for premium skips and boosters.
- **Conversion Rate**: Balanced to maintain game pacing and reward player effort.

## 2. Progression System
- **Level Scaling**: Exponential cost curves for upgrades to balance long-term engagement.
- **Booster Multipliers**: Stackable percentage bonuses applied to core earnings.

## 3. Ad Integration Engine
- **Cooldown Timers**: Prevents ad fatigue by limiting consecutive views.
- **Reward Payout**: Instant triggering of bonuses upon successful ad completion callback.
