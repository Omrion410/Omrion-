# Gameplay Loops

## Core Loop
1. **Action**: Tap / Collect generated funds.
2. **Reward**: Earn primary currency.
3. **Upgrade**: Spend currency on generators and multipliers.

## Meta Loop
1. **Milestones**: Reach specific income tiers to unlock new levels/zones.
2. **Prestige / Reset**: Reset progress in exchange for permanent prestige multipliers.
3. **Events**: Participate in time-limited challenges for unique rewards.
