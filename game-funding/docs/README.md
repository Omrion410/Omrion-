# Documentation Overview - Game Funding Project

Welcome to the documentation folder for the Game Funding project. This section contains all the strategic, technical, and design specifications required to build, retain, and monetize the game.

## Folder Structure

- `GDD.md`: Game Design Document covering primary mechanics and core flow.
- `MONETIZATION.md`: Detailed strategy for IAP, Ads, and Rewarded mechanics.
- `RETENTION.md`: Player retention strategies, daily loops, and event mechanics.
- `design/`: Subfolder containing detailed game design breakdowns:
  - `OVERVIEW.md`: High-level summary of the game vision.
  - `GAMEPLAY_LOOPS.md`: Core and meta loop diagrams.
  - `SYSTEMS_DESIGN.md`: Detailed system interactions and mechanics.

## Guidelines
Maintain and update these documents as new features or balance changes are introduced.
